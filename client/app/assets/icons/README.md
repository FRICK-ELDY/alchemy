# system_ui icons

Material Design–style silhouettes for Slice E dash UI.

| File | Role |
|:---|:---|
| `mic.png` / `mic_off.png` / `volume_up.png` / `hearing.png` | Top-bar audio stubs |
| `sync.png` | Sync badge stub |
| `close.png` | Close session |
| `power.png` | Exit tab |
| `settings.png` | Settings tab |
| `logout.png` / `exit_to_app.png` | Exit actions |

Generated as static RGBA PNG for offline use (no runtime download).  
Inspired by [Material Icons](https://fonts.google.com/icons) (Apache-2.0). Replace with official SVGs/PNGs when packaging.
