# system_ui icons

Material Design–style silhouettes for Slice E dash UI.

| File | Role |
|:---|:---|
| `mic.png` / `mic_off.png` / `volume_up.png` / `hearing.png` | Top-bar audio stubs |
| `sync.png` | Sync badge stub |
| `close.png` | Close session |
| `power.png` | Exit tab |
| `settings.png` | Settings tab |
| `home.png` | Home tab — [Material Symbols Outlined / home · Fill](https://fonts.google.com/icons?selected=Material+Symbols+Outlined:home:FILL@1) |
| `logout.png` / `exit_to_app.png` | Exit actions / Home logout |

Static RGBA PNG for offline use (no runtime download).  
`home.png` is rasterized from the Google Fonts Icons CDN SVG  
(`materialsymbolsoutlined/home/fill1/48px.svg`, Apache-2.0; Fill ON so it stays solid at 32px).  
Re-fetch: `bash .scripts/fetch-material-home-icon.sh`.  
Other icons are Material-style silhouettes (same family).
