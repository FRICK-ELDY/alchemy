# rust-best-practices（Cursor skill）

[BeautifulRust](https://github.com/morganlinton/BeautifulRust) の `rust-best-practices` を Cursor プロジェクトスキルとして同梱したものです。

| パス | 内容 |
|:---|:---|
| `SKILL.md` | 本体（Rust 作業時にエージェントが参照） |
| `references/` | 各出典のダイジェスト |
| `LICENSE-BeautifulRust` | 上流 MIT ライセンス全文 |

競合時は [`.cursor/rules/implementation.mdc`](../../rules/implementation.mdc) が優先します。

更新する場合は上流を確認し、`SKILL.md` / `references/` を差し替えたうえで Alchemy 向けの precedence 注記を残してください。
